# Odyssey Drive Performance v4

Open **ODYSSEY_DRIVE_ALL_IN_ONE.html**.

## Before driving

1. Unzip the package while parked.
2. Open the HTML file and press **DRIVE MODE**.
3. Leave the default **Reliable offline MP3** mode selected.
4. Press Play before moving. Use vehicle or headset media controls after playback begins.

Do not operate the page while driving.

## Two free speech engines

- **Reliable offline MP3**: 24 bundled eSpeak tracks. No account, network, server, or API key. Normal audio playback is the most likely mode to continue under a locked screen.
- **Live free system voices**: the browser's Web Speech API uses voices already installed on the device and assigns stable voices to recurring characters. This sounds better on many Macs and phones but may stop when the browser sleeps.

## Spoken-versus-staged rule

- Dialogue is spoken by the character.
- Existing narrator turns are spoken by the epic narrator.
- No-text embodied events are classified as either **auditory action** or **silent action**.
- Auditory action is spoken only when the listener needs the event to understand location, identity, causality, possession, violence, ritual, arrival, departure, or recognition.
- Stage directions attached to dialogue describe gaze, body, delivery, and blocking. They remain visual and are never read aloud.
- Micro-actions that do not alter audio comprehension become pauses rather than clumsy narration.
