# The Odyssey — Drive Audio Play

Open `index.html` and tap **START / RESUME** once.

The default Audio Play uses 24 MP3 tracks rendered with the free, open-source eSpeak TTS engine. Tracks advance automatically and ordinary HTML audio is suitable for continuous listening.

The optional Live Cast mode uses the English system voices installed on the device through the browser Speech Synthesis API.

Character payloads are spoken as dialogue. Parenthetical macro-actions needed to follow the story are rewritten as concise narrator prose. Delivery, gaze, objective, subtext, and blocking are never spoken.
